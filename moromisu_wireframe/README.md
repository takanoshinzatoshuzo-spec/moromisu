# 新里酒造 もろみ酢ブランドページ（完成イメージ寄りプロトタイプ）

添付された以下の実素材を反映した、HTML/CSS/JSのみの静的プロトタイプです。

- 新里酒造ロゴ
- 琉球もろみ酢 無加糖 商品画像
- 琉球もろみ酢 加糖タイプ 商品画像
- 沖縄の活力 シークワーサー＆レモン入り 商品画像
- 新里酒造 工場外観写真

## ファイル

- `index.html` … ページ本体
- `style.css` … PC / タブレット / スマホ対応デザイン
- `script.js` … モバイルメニュー、商品診断、スクロール表示アニメーション
- `assets/` … 画像素材

## 実装済み

- 実ロゴ・商品画像・工場写真の反映
- PC / スマホ レスポンシブ
- ファーストビューの商品3種ビジュアル
- もろみ酢説明 / 酒蔵ストーリー / 成分 / 商品一覧 / 飲み方 / 診断 / 製造工程 / FAQ / 購入 / 会社紹介
- 商品診断でおすすめ商品カードを強調
- FAQ（details/summary）
- スマホ固定CTA
- IntersectionObserverによる軽いスクロール演出
- `prefers-reduced-motion` 対応

## 公開前に差し替え・確認が必要な箇所

1. 「購入ページへ」のURL（現在 `#`）
2. お客様の声（現在はレイアウト確認用の掲載イメージ）
3. FAQの目安量・保存方法など、各商品ラベルに基づく正式表記
4. 商品名・原材料・栄養成分・内容量の最終確認
5. 薬機法・景品表示法等に照らした最終文言チェック
6. 必要に応じて飲用シーン写真や製造工程写真を追加

## ローカル確認

`index.html` をブラウザで開くだけでも確認できます。Webサーバー経由で確認する場合は、このフォルダをドキュメントルートとして配信してください。
